# Иллюстрации Glufonde Reader

Файлы WebP находятся в архиве «Glufonde_Reader_WebP_assets.zip», приложенном в переписке с автором. Для завершения обновления нужно извлечь архив и загрузить все 21 файла из папки `assets/img/reader/` в одноимённую папку **этой ветки** через GitHub → Add file → Upload files.

Тексты и изображения уже связаны в `js/lore.js` и `content/10-glava-9.md`.

**Не объединять PR до загрузки изображений.** Проверка `tools/check-assets.js` намеренно сообщает об отсутствующих файлах и защищает сайт от сломанных иллюстраций. После загрузки всех файлов нужно убедиться, что CI прошёл успешно.

WebP созданы из авторских изображений с сохранением пропорций и уменьшением ширины до 1440 пикселей максимум. На маленьких экранах они масштабируются без обрезки. Исходные имена сохранены в нормализованном латинском написании.

Снимок `razkol.webp` по изображению выглядит прибрежным маяком, поэтому его интерпретация как «Разкола» предварительная и может быть скорректирована автором.
