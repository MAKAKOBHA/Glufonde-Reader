# Читалка Glufonde Fracture — Rulebook

Готовая веб-читалка книги правил. Работает без сервера, без регистрации, ничего не отправляет в интернет.
Настройки, закладки и место чтения хранятся только в вашем браузере (localStorage).

## Как открыть на своём компьютере

Дважды щёлкните по `index.html`. Всё. (Если браузер ругается, запустите в папке `npx serve` и откройте показанный адрес.)

## Что где лежит

| Папка / файл | Что это |
|---|---|
| `index.html` | главная страница и читалка |
| `license.html` | страница «Лицензия и авторские права» |
| `content/` | **тексты глав** (файлы `.md`) и `manifest.json` — порядок глав |
| `assets/img/` | обложка, иллюстрации, иконка |
| `assets/fonts/` | **шрифты**: файлы, `fonts.css` (подключение), `fonts.js` (список для настроек) |
| `css/style.css` | оформление; все цвета и шрифты — переменные в начале файла |
| `js/fonts.js` | скрипт смены шрифта заголовков и текста |
| `Sound/ambience/` | **музыка разделов**: `rulebook.mp3`, `lore.mp3` |
| `assets/lore/img/` | картинки для статей «Истории Глюфонде» |
| `js/lore.js` | **статьи «Истории Глюфонде»** (текст на Markdown прямо в файле) |
| `js/ambience.js` | фоновая музыка разделов |
| `js/config.js` | название, автор, версия, год, данные лицензии |
| `js/book-data.js` | **создаётся автоматически**, вручную не править |
| `tools/build.js` | сборка книги из `content/` |

## Как изменить текст или добавить главу

1. Откройте нужный файл в `content/` (обычный текстовый файл) и измените текст.
2. Новая глава: создайте файл `content/15-glava-13.md`, первая строка — `# Глава XIII. Название`.
   Добавьте строку в `content/manifest.json`: `{ "id": "glava-13", "file": "15-glava-13.md" }`.
3. Выполните в папке проекта: `node tools/build.js` (нужен установленный Node.js). Команда проверит главы и обновит `js/book-data.js`.
4. Загрузите изменения на GitHub.

Проще всего: пришлите мне новый текст — я обновлю файлы и пересоберу книгу.

### Разметка в главах

- `# Глава` — название главы (одно на файл), `##` — раздел, `###` — подраздел
- `- пункт` — маркированный список, `1. пункт` — нумерованный
- `**жирный**`, `*курсив*`
- Таблица: `| Навык | Значение |` и строка `| --- | --- |` под заголовком; в ячейке перенос — `<br>`
- Картинка: `![описание](assets/img/файл.png)` (положите файл в `assets/img/`)
- Блоки: 
  ```
  ::: example
  Текст примера
  :::
  ```
  Типы: `example` (Пример), `note` (Примечание, можно свой заголовок: `::: note Прим.`), `important` (Важно!), `formula` (формула).

## Оформление

Дизайн взят из PDF Rulebook: чёрный фон с лёгкой текстурой, золотой текст `#FFC000`, шрифт Times New Roman
(системный, не загружается из интернета; на Linux его заменяет Liberation Serif), тонкие золотые рамки таблиц,
орнамент и обложка из PDF. Светлой темы в PDF нет, поэтому она сделана производной («пергамент» и тёмное золото).
Тёмная тема включена по умолчанию.

Все цвета — переменные в начале `css/style.css`. Картинки из PDF лежат в `assets/img/`:
`cover.jpg` (обложка), `golden-chocolate.jpg`, `eidos.jpg`, `range-penalties.png` (схема дальности стрельбы),
`character-sheet.png` (лист персонажа), `texture.webp` (текстура фона).
Чтобы заменить картинку, положите файл с тем же именем.

## Два раздела: RuleBook и «История Глюфонде»

На главном экране две кнопки. У каждого раздела свои оглавление, поиск, прогресс, закладки в списке и **своя фоновая музыка**. Тема, шрифты и размер текста общие. Переключаться между разделами можно и внутри читалки: кнопки внизу бокового меню.

| Раздел | Где лежит текст | Нужна ли сборка |
|---|---|---|
| RuleBook | `content/*.md` и `content/manifest.json` | да: `node tools/build.js` |
| История Глюфонде | `js/lore.js` (текст прямо в файле) | **нет**: сохранили и обновили страницу |

### Как добавить статью в «Историю Глюфонде»

1. Откройте `js/lore.js` в любом текстовом редакторе (Блокнот, VS Code).
2. Найдите последнюю статью. После её закрывающей `}` поставьте запятую и вставьте новый блок:

```
    {
      id: 'stab',
      md: `# Стаб

Страна страстных людей, шумных семейных застолий и талантливых инженеров.

## География

Текст раздела…

- пункт списка
- ещё пункт
`
    }
```

3. `id` — короткое имя латиницей без пробелов и без повторов. Адрес статьи получится `#/read/lore-stab`.
4. Между обратными кавычками ` ` пишется текст. Первая строка обязательно `# Название статьи`. Заголовки `##` и `###` попадают в оглавление.
5. **Нельзя** использовать внутри текста обратную кавычку ` и сочетание `${`. Если ошиблись, читалка покажет пустой раздел: проверьте запятые между блоками и кавычки в начале и конце.
6. Порядок статей в оглавлении — порядок блоков в файле.

Разметка текста: `**жирный**`, `*курсив*`, `- пункт`, `1. пункт`, таблицы, блоки `::: note Заголовок … :::` (подробности в разделе «Разметка в главах» выше). Текст из Word можно вставлять абзацами; заголовки пометьте решётками.

### Как добавить картинку в статью

1. Положите файл в папку `assets/lore/img/` (имя латиницей, без пробелов): например `assets/lore/img/map-umora.jpg`.
2. В нужном месте статьи, отдельной строкой, напишите:

```
![Карта Уморы: столица Зровер и крупные города](assets/lore/img/map-umora.jpg)
```

Текст в квадратных скобках — описание картинки для незрячих читателей и на случай, если файл не найден. Путь пишется от папки, где лежит `index.html`, без слеша в начале: так он работает и на GitHub Pages в подпапке репозитория.

## Фоновая музыка разделов

| Раздел | Файл |
|---|---|
| RuleBook | `Sound/ambience/rulebook.mp3` |
| История Глюфонде | `Sound/ambience/lore.mp3` |

- Музыка включается, когда вы открываете раздел, и плавно затихает при выходе на главный экран или смене раздела.
- Кнопка с динамиком в верхней панели включает и выключает музыку. Громкость и подробное состояние — в «Настройках чтения». Выбор запоминается.
- Сейчас там временные заглушки (простой гул, сделанный программой). Чтобы поставить свою музыку, положите свой `.mp3` под тем же именем. Трек играет по кругу, поэтому лучше брать зацикленный. Используйте только музыку, которую вам разрешено публиковать.
- Другие файлы и названия разделов задаются в `js/config.js`, поле `books`:

```
books: {
  rules: { title: 'RuleBook',          ambience: 'Sound/ambience/rulebook.mp3' },
  lore:  { title: 'История Глюфонде', ambience: 'Sound/ambience/lore.mp3' }
}
```

- Если файла нет, чтение работает, а в настройках появляется подсказка с путём к файлу.
- Браузеры запрещают автозапуск звука. После обновления страницы музыку нужно включить кнопкой с динамиком. При переходе с главного экрана кнопкой раздела она включается сама.

## Шрифты

Шрифты лежат в папке `assets/fonts/` (латиница, кириллица, греческий; форматы `.woff`). В «Настройках чтения» можно отдельно выбрать **шрифт заголовков** и **шрифт основного текста**. Выбор запоминается; за него отвечает скрипт `js/fonts.js`.

В комплекте: «Как в PDF» (Times New Roman, системный), Liberation Serif, Lora, DejaVu Serif, Liberation Sans, Liberation Mono. Лицензии — в `assets/fonts/licenses/` и `assets/fonts/README.txt`.

**Как добавить свой шрифт:**
1. Положите файл (лучше `.woff2` или `.woff`) в `assets/fonts/`. Убедитесь, что лицензия разрешает использовать его на сайте и что в шрифте есть кириллица.
2. В `assets/fonts/fonts.css` скопируйте любой блок `@font-face` и поменяйте имя семейства и имя файла.
3. В `assets/fonts/fonts.js` добавьте строку в список: `{ id: 'my-font', name: 'Название в меню', stack: "'GF My Font', serif" }`.
4. Обновите страницу — шрифт появится в настройках.

Чтобы шрифт по умолчанию был другим, поставьте нужную запись первой в списке `fonts.js` (запись с `id: 'default'` используется как запасная).

## Автор, версия, год

Откройте `js/config.js`. Версия и год пока пустые и на экране не показываются: впишите значения в кавычках.

## Публикация на GitHub Pages

1. Создайте репозиторий на github.com и загрузите в него **содержимое папки** (чтобы `index.html` лежал в корне).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
3. Через минуту сайт откроется по адресу `https://ваше-имя.github.io/название-репозитория/`.

Все ссылки в читалке относительные, поэтому работают и в подпапке репозитория.
Помните: файлы публичного репозитория может скачать любой, защитить текст от копирования так нельзя.

## Как добавить лицензию

Откройте `js/config.js`, раздел `license`: впишите правообладателя, год, версию и абзацы текста в `paragraphs`.
Когда добавите абзацы, фраза-заглушка на странице лицензии скрывается сама. Читать книгу лицензия не блокирует.

## Горячие клавиши

`/` — поиск, `Esc` — закрыть меню, `Shift + ←/→` — предыдущая/следующая глава.
