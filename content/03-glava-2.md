# Глава II. Создание персонажа

Перед началом игры каждый участник создаёт собственного персонажа. После, в начале игровой сессии игроки распределяют свои навыки с помощью системы архетипов **RollSet.** Она формирует сильные и слабые стороны персонажей.

В результате создания персонажа игрок получает набор модификаторов навыков и рассчитывает основные характеристики, используемые во время игры.

Создание персонажа состоит из трёх этапов:

1. Получение карт архетипов.
2. Определение значений навыков.
3. Расчёт основных характеристик.

## Система RollSet

**RollSet** представляет собой систему распределения характеристик персонажа с помощью карт архетипов.

Каждая карта изменяет значения определённых навыков, усиливая одни способности и ослабляя другие. Благодаря этому каждый персонаж обладает уникальным набором сильных и слабых сторон.

Всего в системе используется **27 карт архетипов**.

### Получение карт

Перед началом игры все игроки определяют порядок выбора карт.

Каждый участник бросает **два кубика d10**.

Игрок с наибольшим результатом выбирает первым. Остальные игроки получают право выбора по убыванию результатов бросков.

После определения очередности каждый игрок выбирает **три карты архетипов**.

### Правила выбора

Карты располагаются **рубашкой вверх**.

Игрок не знает содержимого карты до момента выбора.

После того как карта была выбрана и открыта, заменить её другой нельзя.

Каждая выбранная карта становится частью персонажа до окончания партии или смерти персонажа.

## Навыки персонажа

Каждый персонаж обладает девятью основными навыками.

Навыки отражают способности персонажа в различных сферах деятельности и используются при выполнении большинства проверок.

Значение навыка может быть как положительным, так и отрицательным.

Положительное значение облегчает успешное выполнение проверок.

Отрицательное значение затрудняет их прохождение.

На показатели навыков могут временно влиять различные игровые эффекты, включающие себя пищу, напитки, медикаменты и другие обстоятельства. Подобные изменения определяются Мастером игры.

### Физиология

Физиология отражает физическую силу, выносливость и способность организма переносить нагрузки.

Навык применяется при проверках, связанных с:

- рукопашным боем;
- поднятием тяжёлых предметов;
- выживанием в тяжёлых условиях;
- другими действиями, требующими физической силы.

### Моторика

Моторика определяет ловкость, точность движений и координацию.

Навык применяется при проверках, связанных с:

- уклонением от атак;
- взломом замков;
- метанием предметов;
- преодолением препятствий;
- другими действиями, требующими точности движений.

Значение Моторики используется при расчёте Хитов.

### Внимание

Внимание отражает наблюдательность персонажа и способность замечать детали окружающего мира.

Навык используется при:

- поиске скрытых объектов;
- визуальном анализе;
- обнаружении деталей;
- осмотре местности.

### Интуиция

Интуиция отражает внутреннее чутьё персонажа и способность чувствовать опасность без очевидных причин.

Навык применяется при:

- предчувствии угрозы;
- принятии решений при недостатке информации;
- других проверках, связанных с шестым чувством.

### Эмпатия

Эмпатия отражает способность понимать эмоциональное состояние окружающих.

Навык используется при:

- чтении языка тела;
- выявлении лжи;
- распознавании эмоций;
- понимании намерений собеседника.

### Разум

Разум определяет интеллект, логическое мышление и способность анализировать информацию.

Навык применяется при:

- логических рассуждениях;
- поиске решений;
- аргументации;
- анализе информации.

Значение Разума используется при расчёте Психики.

### Авторитет

Авторитет отражает положение персонажа в обществе, уверенность в себе и способность воздействовать на окружающих своим статусом.

Навык применяется при:

- оказании давления на собеседника;
- демонстрации власти;
- сохранении самообладания в сложной ситуации.

Значение Авторитета также используется при расчёте Психики.

### Запугивание

Запугивание отражает способность добиваться желаемого посредством страха.

Навык применяется при:

- угрозах;
- принуждении;
- психологическом давлении;
- попытках заставить другого персонажа изменить своё поведение.

Значение Запугивания также используется при расчёте Психики.

### Манипуляция

Манипуляция отражает способность влиять на окружающих словами и поведением.

Навык применяется при:

- обмане;
- убеждении;
- соблазнении;
- ведении переговоров;
- красноречии.

## Архетипы и итоговые значения

После выбора трёх карт игрок суммирует все полученные модификаторы.

Каждый навык начинается со значения **0**.

После этого к нему последовательно применяются все изменения, указанные на выбранных картах.

Получившееся число становится постоянным значением навыка персонажа.

::: example
Игрок получил следующие модификаторы:

| Навык | Изменение |
| --- | --- |
| Физиология | −1 |
| Моторика | −2 |
| Внимание | +1 |
| Интуиция | +1 |
| Эмпатия | 0 |
| Разум | +2 |
| Авторитет | +1 |
| Запугивание | 0 |
| Манипуляция | 0 |
:::

Именно эти значения будут использоваться во всех проверках до тех пор, пока они не изменятся игровыми эффектами.
